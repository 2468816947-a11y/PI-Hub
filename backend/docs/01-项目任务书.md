## 2 项目背景与业务描述

本项目选题为**电力场站设备巡检数据集成平台**(选题 2·进阶),业务场景为变电站/光伏场站巡检:

- **无人机高空广域巡查**:无人机沿预设航线飞行,高空拍摄杆塔、光伏板等高空设备,回传航拍图像元数据、GPS 位置、飞行状态;
- **机器狗地面抵近复核**:机器狗进入地面设备区(变压器、开关柜、逆变器等),近距离完成**红外测温**与**环境传感器**(温度、湿度、气体)采集,回传设备运行状态,对无人机发现的高空隐患进行地面复核确认;
- **平台企业级集成**:平台统一管理设备台账、下发巡检任务、接收设备上报数据,通过 **Kafka** 完成消息流转、**HDFS** 存储巡检影像大文件、**MongoDB** 存储设备/任务/告警结构化数据、**Elasticsearch** 实现故障记录全文检索与多维度统计分析、**Nginx** 对外提供统一网关,最终输出巡检报告,实现"高空发现隐患、地面复核确认、数据闭环归档"的巡检业务闭环。

本项目为**软件集成仿真开发实践**,不涉及实体无人机、机器狗硬件;硬件设备采用**软件仿真模拟**(数据生成器 + 消息生产者)方式完成数据与指令流转,重点训练软件系统集成、中间件部署、分布式存储、消息队列、检索引擎、负载均衡与业务平台开发能力。

## 3 项目目标

### 3.1 业务目标

实现电力场站空地协同巡检业务闭环:完成设备统一接入(无人机、机器狗注册/心跳/状态上报)、巡检任务下发与执行跟踪、消息流转(Kafka 生产消费)、分布式存储(影像入 HDFS、结构化数据入 MongoDB)、告警处理(测温超阈值/设备异常判定)、检索分析(按设备、时间、告警类型、地理位置检索 + 多维统计)、巡检报告输出、Nginx 统一网关与 Web 可视化展示。

### 3.2 技术目标

- 熟练使用 **Hadoop HDFS、MongoDB、Kafka、Nginx、Elasticsearch + Kibana** 五类强制中间件组件,全部完成部署、配置、联调;
- 基于 **Docker Compose** 完成单机多容器集群仿真部署,理解各组件在分布式企业应用集成架构中的位置与数据流转关系;
- 掌握组件部署调试、日志排查、系统测试与性能优化方法,能够独立定位并解决分布式系统集成问题。

### 3.3 素质目标

培养精益求精、追求卓越的大国工匠精神;强化团队协作、文档撰写、技术总结、答辩汇报能力;培养自主查阅官方文档、跟踪新技术的能力;把工程实践严谨性落实在需求调研、编码、测试、文档的每个细节中。

## 4 主要功能任务(强制完成)

1. **设备仿真模块**:无人机、机器狗仿真器,模拟设备注册、心跳、状态上报(在线/离线、电量、故障)、航拍图像元数据、红外测温数据、环境传感器数据上报;
2. **消息中间件数据流转**:Kafka 实现消息生产、消费、持久化、路由、分区;设备仿真端作为生产者上报数据,业务服务作为消费者消费消息;支持平台通过 Topic 下发任务指令消息至设备仿真端;
3. **分布式存储**:巡检影像文件存入 HDFS(WebHDFS 接口);设备、任务、告警结构化数据存入 MongoDB;
4. **检索分析**:巡检事件、告警数据写入 Elasticsearch,支持按设备编号、时间范围、告警类型、地理位置(geo 检索)检索,实现告警类型分布、设备告警排行、时间趋势等多维聚合统计,Kibana 可视化仪表盘;
5. **Nginx 网关**:前端静态资源托管 + 后端服务反向代理,双实例负载均衡基础策略,基础安全配置(隐藏版本号、请求体限制、CORS、简单限流);
6. **基础业务功能**:设备台账管理、巡检任务下发、告警展示与处置、历史任务查询、巡检报告生成;
7. **系统测试**:功能测试、接口测试、简单性能测试,记录测试用例与测试结果,完成性能优化。

**拓展选做任务(加分)**:简单权限认证、任务执行日志完整归档、模拟多台无人机 + 多台机器狗并发上报压力测试、数据备份恢复演示。

## 5 技术栈要求

| 类别 | 选型 | 说明 |
| --- | --- | --- |
| 容器环境 | Docker + Docker Compose | 单机容器模拟多节点集群,统一镜像版本规避兼容冲突 |
| 分布式文件系统 | Hadoop HDFS | 巡检图片大文件存储,WebHDFS REST 接口访问 |
| 分布式数据库 | MongoDB | 设备/任务/告警/文件元数据结构化存储 |
| 消息中间件 | Kafka(KRaft 模式) | 设备上报、指令下发消息生产消费、持久化 |
| 检索引擎 | Elasticsearch + Kibana | 巡检事件检索、聚合统计、可视化仪表盘 |
| 网关 | Nginx | 反向代理、负载均衡、限流、安全配置 |
| 后端 | Java 17 + Spring Boot 3.x | spring-kafka、spring-data-mongodb、spring-data-elasticsearch |
| 前端 | Vue 3 + Vite + ECharts | 设备地图、状态大屏、告警可视化、统计图表 |

## 10 风险与注意事项

| 风险 | 应对措施 |
| --- | --- |
| 中间件组件版本兼容性冲突 | 统一使用 Docker 官方镜像固定版本,Docker Compose 一键编排 |
| Kafka 生产者消费者联调失败 | 重点排查 Topic 配置、网络连通性、序列化方式,使用 kafka-console-consumer 命令行验证 |
| Elasticsearch 地理检索报错 | 索引映射中位置字段定义 geo_point,查询使用 geo_distance/geo_bounding_box |
| Nginx 跨域、负载均衡策略调试 | upstream 配置轮询策略,location 分段代理,日志定位 |
| HDFS 文件上传下载权限问题 | 检查 WebHDFS 用户权限与 NameNode 连通性,数据目录挂载到宿主机 |
| 进度滞后 | 按阶段里程碑检查,每周例会同步,任务责任到人 |

**学术诚信**:禁止直接复制网络完整项目代码不做修改;禁止抄袭报告文档;引用技术文档、开源代码需标注来源;如实记录项目遇到的问题,不虚构测试结果。
