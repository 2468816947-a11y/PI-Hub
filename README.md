# 无人机机器狗空地协同巡检集成平台

> **选题 2(进阶):电力场站设备巡检数据集成平台**
> 《企业应用开发实践》课程项目 —— 软件工程专业第 7 学期,32 学时(课内)+ ≥64 学时(课外)

## 项目简介

模拟变电站/光伏场站巡检业务场景:无人机高空广域巡查(航拍图像 + GPS),机器狗地面抵近复核(红外测温 + 环境传感器),平台通过 **Kafka** 完成消息流转、**HDFS** 存储巡检影像、**MongoDB** 存储结构化数据、**Elasticsearch + Kibana** 实现故障记录检索与多维统计分析、**Nginx** 提供统一网关与负载均衡,实现"高空发现隐患、地面复核确认"的巡检业务闭环。本项目为软件集成仿真开发实践,不涉及实体硬件设备。

## 技术栈

| 类别 | 选型 |
| --- | --- |
| 容器 | Docker + Docker Compose(单机模拟集群) |
| 消息中间件 | Kafka(KRaft) |
| 分布式文件系统 | Hadoop HDFS(WebHDFS 接口) |
| 分布式数据库 | MongoDB |
| 检索引擎 | Elasticsearch + Kibana |
| 网关 | Nginx |
| 后端 | Java 17 + Spring Boot 3.2 |
| 前端 | Vue 3 + Vite + Element Plus + ECharts |
